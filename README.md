# Apple × Galaxy S26 Ultra — Scrolling Battle

A cinematic, fan-made comparison landing page built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser. No build process, Node.js or server is required.

For the smoothest local experience, use VS Code + Live Server, or any simple static web server.

## Publish FREE with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a **public** repository named `apple-vs-galaxy`.
3. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
4. Open the repository's **Settings**.
5. Select **Pages** under the Code and automation section.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`.
8. Click **Save**.
9. Wait a minute or two. GitHub will show your published URL.

It will normally look like:

https://YOUR-USERNAME.github.io/apple-vs-galaxy/

- Change colors and typography in `style.css`.
- Change text/content in `index.html`.
- Change animations and interactions in `script.js`.
- Replace the CSS phone mockups with your own licensed product images if desired.
